# SustainAI Project Requirements

## Sustainability Pillars (India Context)
- **Hard Water Management:** The system MUST include a module for identifying and mitigating hard water issues in residential urban clusters (specifically Delhi/NCR).
- **Urban Greenery:** The system SHALL provide a dashboard for mapping green infrastructure investments as per MoHUA guidelines.
- **Energy Efficiency:** The system MUST integrate with the National Building Code (NBC) of India and GRIHA standards for building assessments.

## Technical Constraints
- **Stack:** Node.js/TypeScript backend, React frontend.
- **Deployment:** AWS (using Graviton instances for cost/carbon optimization).
- **APIs:** Integration with Indian Open Data (data.gov.in) for air quality and water table levels.
